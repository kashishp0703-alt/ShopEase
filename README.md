# 🛍️ ShopEase — React E-Commerce Website

A modern, responsive **frontend e-commerce website** built with **React.js**, **Tailwind CSS**, and **React Router**.

ShopEase provides a complete shopping experience with product browsing, search and filtering, product details, wishlist, shopping cart, checkout, and order management.

---

## 🚀 Live Demo

🔗 **Live Demo:** https://shopease-delta-two.vercel.app/

🔗 **GitHub Repository:** https://github.com/kashishp0703-alt/ShopEase

---

## ✨ Features

* 🏠 Modern and responsive homepage
* 🛍️ Product listing and shopping page
* 🔎 Product search and filtering
* 📦 Product details page
* ❤️ Wishlist functionality
* 🛒 Shopping cart functionality
* ➕ Increase/decrease product quantity
* 💳 Checkout flow
* 📍 State and city selection
* 👤 Login and signup UI
* 📋 Order history
* ✅ Order success page
* 💾 Cart and wishlist persistence using LocalStorage
* 🔄 Product data fetched from Fake Store API
* 🧭 Client-side routing with React Router
* 📱 Responsive design for mobile, tablet, and desktop
